# cad-lab Desktop

ИИ-ассистент для работы в открытом КОМПАС-3D. Попросите агента изменить деталь, измерить зазор в сборке или помочь с чертежом. Результат можно открыть и доработать в CAD.

**[Скачать cad-lab для Windows x64](https://cad-lab.xyz/app/?utm_source=github&utm_medium=referral&utm_campaign=desktop_download&utm_content=cad-lab-desktop#download)**

На сайте есть шаги установки и подключения КОМПАС-3D. Установщик и контрольные суммы доступны также в [последнем релизе](https://github.com/cad-lab-ai/cad-lab-desktop/releases/latest).

## Первый запуск

1. Запустите `cad-lab-<версия>-x64.exe`. Установка выполняется для текущего пользователя. Установщик выпускается без подписи Authenticode.
2. Для работы в КОМПАС-3D v19 и новее установите [KompasAgent](https://github.com/cad-lab-ai/kompas-mcp#установка) и добавьте плагин «КОМПАС-3D» через «Маркетплейс → Плагины» в cad-lab.
3. Настройте агента, откройте модель в КОМПАС-3D и начните с проверки, например попросите измерить габариты детали.

cad-lab получает обновления из этого репозитория. Загрузка установщика и обновлений доступна без учётной записи GitHub.

## Файлы выпуска

| Файлы | Назначение |
|---|---|
| `cad-lab-<версия>-x64.exe` | Установщик Windows |
| `latest.yml`, `desktop-version-windows.json` | Метаданные автоматического обновления |
| `*.blockmap` | Данные для загрузки разницы между версиями |
| `SHA256SUMS` | Контрольные суммы файлов |

Архивы **Source code** содержат документацию этого репозитория. Установщик находится в разделе **Assets** релиза.

## Поддержка

Об ошибках приложения сообщайте в [Issues](https://github.com/cad-lab-ai/cad-lab-desktop/issues). Укажите версию cad-lab, ОС и шаги воспроизведения. Для примера подойдёт открытая модель без конфиденциальных данных.

## Сторонние компоненты

Приложение использует bb и другие сторонние компоненты. Их лицензии и уведомления входят в поставку. Исходный код приложения хранится в частном репозитории.
