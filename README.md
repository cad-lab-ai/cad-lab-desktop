# cad-lab Desktop

Ассистент инженера для работы с CAD на своём компьютере.

Этот репозиторий содержит **готовые установщики, файлы обновления и документацию**.
Исходный код приложения разрабатывается в закрытом репозитории и сюда не публикуется.

## Скачать

Готовые версии будут доступны в [Releases](https://github.com/cad-lab-ai/cad-lab-desktop/releases).
Если список Releases пуст, первый выпуск ещё не опубликован.

После установки cad-lab проверяет обновления этого репозитория. Релизы upstream bb
не используются для обновления cad-lab. Загрузка обновлений не требует GitHub-токена.

## Файлы выпуска

| Файлы | Назначение |
|---|---|
| `cad-lab-<версия>-x64.exe` | Установщик Windows |
| `cad-lab-<версия>-arm64.dmg`, `.zip` | Установка и обновление macOS, если платформа включена в выпуск |
| `cad-lab-<версия>-x64.AppImage` | Linux, если платформа включена в выпуск |
| `latest*.yml`, `desktop-version*.json` | Метаданные автоматического обновления |
| `*.blockmap` | Данные для загрузки разницы между версиями |
| `SHA256SUMS` | Контрольные суммы файлов |

Автоматические архивы GitHub **Source code** содержат только документацию этого
репозитория. Это не исходный код приложения и не установщик.

## Поддержка

О проекте и контакты: [cad-lab.xyz](https://cad-lab.xyz).
Об ошибках приложения можно сообщить через [Issues](https://github.com/cad-lab-ai/cad-lab-desktop/issues).
Укажите версию cad-lab, ОС и шаги воспроизведения. Не прикладывайте токены, пароли
и закрытые модели заказчиков.

## Сторонние компоненты

Приложение использует bb и другие сторонние компоненты. Их уведомления и лицензии
сохраняются в поставке; наличие открытых компонентов не означает публикацию
исходного кода cad-lab в этом репозитории.
