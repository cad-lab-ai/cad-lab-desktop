# Сообщить о проблеме безопасности

Для сообщений, содержащих закрытые данные, используйте контакты на
[cad-lab.xyz](https://cad-lab.xyz). Не публикуйте действующие токены, персональные
данные или закрытые CAD-модели в публичных Issues.

Обновления cad-lab распространяются через Releases этого репозитория.
Ключи GitHub нужны только сопровождающим для загрузки файлов и не входят в приложение.
